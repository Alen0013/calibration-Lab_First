Вариант 25 — калибровка вероятностей. Дата проверки — 22.11.2026. Рецензию подготовил ChatGPT по приложению А предоставленной методички. Баллы и итоговая оценка не назначаются. Рассматриваются фактические файлы и результаты ЛР1; визуальная работа браузера и действия в удалённом GitHub не подтверждаются просмотром конфигурации.

## Вердикт

**ЛР1 готова с замечаниями для локальной проверки. Полный комплект окончательной сдачи пока не завершён.** Анализ, обязательные машинные артефакты, отрицательные контроли и повторение представлены. Остаются удалённая часть GitHub, персонализация и подтверждение формата видеосдачи.

ЛР2–ЛР8 — вне текущего задания; проверить невозможно, соответствующие отчёты не предоставлены. Отсутствие этих работ не считается дефектом ЛР1.

## Проверенные результаты

- Паспорт данных, EDA и калибровочная диаграмма присутствуют. В отчёте описаны 569 наблюдений и 30 признаков; численные сводки согласуются с `eda_stats.csv`, значения метрик — с `calibration_metrics.csv`. Основной MLflow run — `370aa595b62543838eb3cd0d501ecb5b`, коммит кода — `27348d56b63837354ef700f61c13cd723a206680` [результаты](results.json), [отчёт](lab1_report.md).
- SHA-256 и размер сырых данных проверяются по закреплённому эталону. Копия манифеста совпадает с основным файлом. Подмена байта действительно отклонена, исходный файл сохранён; переписывание манифеста не позволяет обойти эталон [hash_tamper.json](hash_tamper.json), [валидатор](../../src/calibration_lab/data.py).
- Три настоящих коммита в изолированном репозитории заблокированы: стиль, искусственный секрет, превышение размера. У каждого ненулевой код и неизменный HEAD. Копия конфигурации идентична действующей [precommit_controls.json](precommit_controls.json), [журнал](precommit_block.log).
- Повторы `a798160fb1df496391eed304040e7797` и `eb7c0d5433c445758b6c3a1aaf6a1e90` зарегистрированы в MLflow. Совпадают все десять детерминированных файлов; максимальная разность метрик равна нулю. Хеши текущих файлов также совпадают с повтором. Объявлен точный повтор внутри одного окружения [reproducibility.json](reproducibility.json).
- Чистая установка, зависимости, 27 автоматических тестов и локальный pre-commit прошли проверку. Работающий HTTP-процесс прошёл 18 проверок, включая запуск `verify`. Это не визуальная проверка интерфейса [local_checks.json](local_checks.json), [app_smoke.json](app_smoke.json).

В [коде анализа](../../src/calibration_lab/analysis.py) scaler и модель обучаются на train, калибратор — на отдельной calibration-части. Test применяется только для оценки. Рост Brier с 0,023921 до 0,028697 в отчёте интерпретирован как ухудшение; улучшение после калибровки не приписывается результатам.

## Замечания и рекомендации

**R1 — завершить удалённый процесс.** Репозиторий `Alen0013/calibration-lab1` создан владельцем, но на момент проверки содержит только первоначальный README. Попытка записи через подключение получила HTTP 403 `Resource not accessible by integration`. Стандартная авторизация GitHub CLI после подтверждения пользователя не завершилась из-за сетевой политики среды выполнения. Исходники не загружены, удалённый CI, защита main и человеческое ревью не подтверждены. Для обычной публикации с компьютера владельца подготовлен `PUBLISH_GITHUB.bat`; наличие скрипта не считается выполненной публикацией. После его реального выполнения нужны ссылки на PR/Actions и проверка настроек защиты [состояние GitHub](github_status.json), [порядок публикации](../../docs/publish_github.md).

**R2 — заполнить авторство и личный комментарий.** Шапка отчёта и `results.json` содержат «Автор не указан». Автор должен внести достоверные сведения, прочитать рецензию и самостоятельно подтвердить или переработать критический комментарий. Незаполненный личный чек-лист не выдаётся за проверку обучающегося [чек-лист](../../defense_checklist.md).

**R3 — различать CLI-демонстрацию и скринкаст интерфейса.** Ролик `lab1_demo_cli.mp4` имеет продолжительность 210 секунд по ffprobe. Он воспроизводит реальные сохранённые выводы команд и графики с увеличенными паузами; это прямо указано в `video_capture.json`. Запись браузерного окна отсутствует. Если для сдачи требуется управление графическим приложением, нужно записать его на компьютере обучающегося по подготовленному сценарию. Скрипт записи сам по себе не подтверждает успешную запись GUI [манифест видео](video_capture.json), [сценарий](../../docs/video_script.md).

**R4 — уточнение окружений внесено.** Среда основного прогона отдельно сохранена в [run_environment.json](run_environment.json) и [requirements-run.txt](../../requirements-run.txt): SciPy 1.17.0, joblib 1.5.3, threadpoolctl 3.6.0. Это расширенный снимок того же интерпретатора после прогона; все версии, изначально записанные в `results.environment`, совпадают. По активным `Requires-Dist` рекурсивно зафиксированы 56 необходимых сторонних пакетов, без посторонних унаследованных библиотек; отсутствующих зависимостей и нарушений ограничений нет. `requirements-lock.txt` и [local_checks.json](local_checks.json) отдельно описывают чистую установку с другими транзитивными версиями. Снимок основного прогона относится к указанным Linux и Python. Точное совпадение метрик доказано внутри исходной среды; совпадение между средами не проверялось и не заявляется.

Приоритет: R1 и R2 закрывают комплект сдачи; R3 закрывает требование к форме демонстрации. Уточнение R4 выполнено, его ограничения нужно сохранить в окончательном описании.

Первоначальная неоднозначность среды устранена раздельными снимками; межсредовой паритет чисел не проверялся. Отсутствие серверных доказательств и записи GUI не скрыто в отчёте, но остаётся незавершённой частью сдачи.
