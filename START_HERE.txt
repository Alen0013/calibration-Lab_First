ЛР1. Вариант 25 — калибровка вероятностей

ПУБЛИКАЦИЯ ИСХОДНИКОВ НА GITHUB

1. Распакуйте весь архив. В этой папке должны остаться PUBLISH_GITHUB.bat,
   scripts/publish_github.py и calibration_lab1.bundle.
2. На Windows запустите PUBLISH_GITHUB.bat двойным щелчком.
   Нужны установленные Python 3.12 и Git. Научные библиотеки для загрузки не нужны.
3. Если откроется вход GitHub, подтвердите его в аккаунте Alen0013.
   Дождитесь итогового сообщения. Проверки GitHub Actions могут занять несколько минут.

Репозиторий: https://github.com/Alen0013/calibration-lab1
Скрипт сохраняет результат в artifacts/github_publication.json и журнал
в artifacts/github_publication.log. При ошибке он останавливается и показывает причину.
Публикация подтверждается фактическим появлением исходников в GitHub и итоговым
результатом сценария. Само наличие этого архива не означает, что код уже загружен.
Подробности и повторный запуск описаны в docs/publish_github.md.

ВИДЕО ДЛЯ ПРИКРЕПЛЕНИЯ

lab1_demo_cli.mp4 — готовая демонстрация реальных выводов команд и графиков,
