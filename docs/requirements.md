# Требования к лабораторной работе 1

Основание — предоставленная методичка `labs_new (1)(1).docx`, раздел «Общие сведения», карточка варианта 25, раздел «Общие требования к артефактам» и «ЛР 1». Тема варианта — калибровка вероятностей на наборе `load_breast_cancer`. Результат этой работы — воспроизводимый разведочный анализ и настроенный порядок внесения изменений в Git.

## Границы работы

В этой работе требуется показать проблему калибровки на графике и подтвердить выводы числами. Сравнение логистической регрессии до и после сигмоидальной калибровки служит иллюстрацией проблемы. Оно не заменяет полный эксперимент лабораторной работы 2. Нейросеть, генератор данных, промышленный API и нагрузочные испытания относятся к последующим работам. Режим чтения чанками обязателен в работах 2–4, а не в работе 1.

## Условия оформления

Отчёт размещается в `reports/LAB1/`; имена файлов пишутся строчными латинскими буквами с подчёркиваниями. В шапке указываются вариант, работа, дата, автор, хеш коммита кода и хеши данных. Автор и ссылка на GitHub заполняются по реальным сведениям.

Каждое экспериментальное число должно вести к сохранённому прогону или вычисляющему скрипту. Нумерованные выводы формулируются так, чтобы каждый содержал один основной количественный результат. Скринкаст может быть ускорен и сопровождаться текстовыми подписями.

## Что проверяется после подключения GitHub

Публикация репозитория, открытие pull request, успешный GitHub Actions и фактическая защита `main` подтверждаются ссылками и чтением настроек удалённого репозитория. До такой проверки они считаются ожидающими выполнения. Возможность защиты ветки зависит от тарифа и видимости репозитория; условия приведены в [официальной документации GitHub](https://docs.github.com/en/repositories/configuring-branches-and-merges-in-your-repository/managing-protected-branches/about-protected-branches).
